# OIBSIP Web Development & Designing – Level 1 Task 1

## Landing Page

### Project Overview

This project is a responsive and visually polished landing page developed as part of the Oasis Infobyte Web Development & Designing Internship.

The landing page is designed for a fictional productivity platform called **NexaFlow – Smart Workflow**.

### Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Web Design

### Features

- Sticky navigation bar
- Navigation links
- Hero section with headline and subheadline
- Call-to-action buttons
- Features section
- About section
- Call-to-action section
- Responsive design for desktop and mobile
- Consistent color palette
- Clean typography
- Responsive Flexbox and Grid layouts
- Footer section
